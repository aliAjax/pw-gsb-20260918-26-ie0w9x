# hxyfront-62003 法医昆虫学样本记录

源提示词编号：5

做一个法医昆虫学样本记录前端工具，用来记录采样地点、环境温度、尸体暴露阶段、昆虫种类、发育阶段、采样时间、保存方式和鉴定备注。页面需要有样本批次列表、发育阶段筛选、温度记录图、案件样本关联页和单个样本详情卡片。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62003

## 送检时限闭环

- 乙醇保存样本自采集起超过 **72 小时**未送检，或其他保存方式超过 **24 小时**未冷藏（冷藏保存不计超时），记录自动标为「待送检」并锁定鉴定结论，禁止通过。
- 「送检登记」只解除阻断，不代替人工鉴定；阻断解除后仍需人工点击「通过鉴定」。
- 旧记录缺采集时间按「不可送检」处理：不能送检登记，鉴定结论同样锁定。
- 记录、送检登记与鉴定结论均持久化在浏览器 localStorage，不依赖后台。
