# hxyfront-62003 法医昆虫学样本记录

源提示词编号：5

做一个法医昆虫学样本记录前端工具，用来记录采样地点、环境温度、尸体暴露阶段、昆虫种类、发育阶段、采样时间、保存方式和鉴定备注。页面需要有样本批次列表、发育阶段筛选、温度记录图、案件样本关联页和单个样本详情卡片。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62003

## 送检时限闭环

- 乙醇保存样本自采集起超过 72 小时仍未送检，或其他保存方式超过 24 小时未冷藏，记录自动标为「待送检」并禁止鉴定结论通过。
- 送检登记只解除结论阻断，不代替人工鉴定；结论仍需在详情卡片中人工判定。
- 缺采集时间的旧记录按「不可送检」处理，不能登记送检，结论同样不得通过。
- 记录保存在浏览器 localStorage（键：`hxyfront-62003:samples`），刷新后状态与结论保留，无后台依赖。
